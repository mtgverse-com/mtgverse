Dans les séries récentes, il y a Severance, où les personnages se laissent un message vidéo avant de faire une opération qui leur efface la mémoire, pour s'expliquer à eux même après l'opération ce qu'il s'est passé (grosso modo, pour ne pas trop vous spoiler cette excellente série).

Dans les films, et c'est plus quelqu'un qui passe le message pour quelqu'un d'autre, mais le personnage est conscient de ce qu'il se passe dans les deux époques : la scène dans Looper où un gars dans le passé se fait graver de force une adresse sur le bras pour que son moi dans le futur la voit est assez marquante, surtout dans le média utilisé.
Bon après il se fait démembrer membre par membre, depuis le passé, donc selon la cible du projet pédagogique c'est probablement pas top.
