FANTOME // Alignement loup

Mordre les jarrets, unique, actif, nuit, offensif/scrutin : tu désignes deux joueurs: ils ne peuvent plus blesser personne pour le reste de la N (mais leurs blessures déjà infligées comptent toujours)

Ta gueule, c'est magique
CHOIX A FAIRE chaque début de Jour

soit tu as
Forme physique : récursif, actif, de jour, offensif: tu cibles un joueur, il est stun (même les pouvoirs déclenchés ou statiques, sauf les malus)

soit tu as
Forme spectrale, permanent, déclenché/statique, défensif+malus : renvoi de pouvoir permanent chez l'envoyeur + malus 0 blessure infligée pour toute la nuit suivante. Pouvoir non combotable avec l'objet Toison d'or (tu comprendras plus tard)
