De mémoire, la démission est un motif de retrait, quand tu as déjà de l'argent placé sur un PEE. Id est : j'ai 10k placé, je démissionne, je peux les retirer avant les 5 ans minimum pour retirer sans payer d'impôt.

En revanche, le fait que tu aies déjà démissionné AVANT d'avoir placé l'argent n'est pas un fait générateur de retrait sans payer d'impôt. Tu as un certain nombre d'autres faits générateurs (pacs, enfant, résidence principale, licenciement, handicap etc), mais le fait générateur doit intervenir après le placement de la somme.

Si tu choisis le retrait anticipé sans raison valable, tu paieras un Impôt sur le revenu à ton taux marginal.
Les tomates mises avec les aromates se parfument et évitent partiellement les limaces. Ce qui n'empêche pas les règles, pas d'ail avec les tomates; les déchets de table c'est très bien au compost mais pas sous le lit.
