La Quete du dragon des tunnels

Pour cette quete, nous avons besoin de 5 aventuriers courageux ! Tout le monde peut participer. Lors de cette quete (et les futures), il peut y avoir des bonus, rien, des malus.

Vous pouvez vous proposer, vous pouvez proposer les autres, c'est comme vous voulez. La seule contrainte est que si vous votez (en vert), pour la quete, cela doit etre impérativement sous ce format :

Joueur A / B / C / D / E ++ Chef de Quete => Joueur (A ou B ou C ou D ou E).

Le chef de quete doit faire imperativement partie de la quete, vous ne pouvez pas choisir un joueur qui n'est pas dans votre liste. C'est le chef de quete qui décidera comment attribuer les bonus/malus éventuels.

On dépile Jeudi à 21h.

Ex :

Je vote pour Pazu/Joey/Mitlamit/Athanor/Bill ++ Chef de Quete => Joey

N'oubliez pas que vous avez aussi un bucher vendredi, vote en rouge classique, et je ne compte jamais les un-vote.
