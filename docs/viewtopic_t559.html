Si vous pensez que les auteurs / éditeurs ne font pas de conneries en rédigeant ce type de règles vous vous fourvoyez...
Les gens jouent avec les règles du jeu (en général) et avec celles du groupe social que constitue la table (toujours). Les éditeurs/auteurs sont biaisés parce qu'ils ont leurs propres règles implicites et ne se rendent pas forcément compte que celles-ci sont implicites.
Ajoutez à ça que les règles de ce type de jeux doivent être concises et t'as presque jamais une règle de jeux de mots écrites avec le niveau de précision qu'on aimerait trouver.
