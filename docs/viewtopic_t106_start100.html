Dans le genre anecdote familiale....

Le jour de la naissance de ma soeur, mon père, en allant à l'état civil, croise son frère, dont la femme venait aussi d'accoucher le même jour. Ils se demandent mutuellement quel est le prénom choisi pour leur fille. Pas de bol, les deux ont choisi le même : Pauline.
Ils décident que la première a être née peut garder le prénom choisi, ça sera donc ma soeur. Notre cousine sera renommée Aline au dernier moment.

Heureusement qu'ils se sont croisés, parce que sinon, les deux Pauline avec le même nom, nées le même jour dans la même ville, je vous raconte pas le bordel a l'état civil. Déjà qu'en allant dans le même lycée, l'administration se plantait sans arrêt malgré les prénoms sensiblement différents...
