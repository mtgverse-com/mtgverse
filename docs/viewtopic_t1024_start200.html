Votre table ronde sera donc composée de :

table.JPG

Première mission pour cette table ronde, histoire de vous mettre dans le bain ! Vous allez devoir décider quel PNJ Villageois activer ! (Pour vendredi 21h au plus tard). Pour cela, les joueurs assis à la table ronde vont voter (en vert) pour donner le PNJ, et la cible. (Ex : Je choisi Guenievre, pour Pazu)

Les PNJ Villageois :

Belt : Le joueur choisi recevra un Token Bouffe - Vin. (Counter préventif : vous n'avez pas accès à l'information de ce que fait un token bouffe)
Guenievre, Reine de Bretagne : Tu es considéré comme un roi/reine. (Ce PNJ se rajoutera à la fiche de son possesseur).

Les PNJ Loups :

Roparzh : Le joueur choisi recevra un Token Bouffe - Vache
Ketchatar, Roi d'Irlande : Tu es considéré comme roi / reine. (Ce PNJ se rajoutera à la fiche de son possesseur).

Villageois et péons ont des choix communs.
-> Ajouter un token roi/reine. On ne sait pas ce que cela fait mais c'est vraisemblablement quelque chose de positif.
-> Ajouter un token bouffe. Token "Vin" pour les villageois, Token "Vache" pour les loups.

Les effets doivent être différents. Le vin ça sonne pas trop bien je trouve, ça rend ivre et j'ai plutôt l'impression que l'effet va pas être bon (genre freeze ou ne peut pas voter ?)
Le token vache parait lui un peu meilleur, ça rend un peu plus fort..

Donc de mon côté pour le village je préfèrerai qu'on distribue un token roi/reine. On a plus de chance de le voir arriver sur un villageois que sur un loup.
