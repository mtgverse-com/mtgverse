Je trouve juste qu'on laisse des portes ouvertes alors qu'on peut optimiser le truc.
Les risques c'est :
- que les loups dégagent csa (s'ils peuvent dégager un pnj). Ils virent alors un pnj plutôt fait pour eux.
- que les loups activent csa dans un de leurs pouvoirs le lundi. Alors Sacem sera actif J1/N1.

Dans le cas du pire on a :
- Dégagé attaché de presse.
- Dégagé CSA.
- Pas de pouvoirs J1/N1.

Dans le cas du meilleur on a :
- Degagé CSA, SACEM et attaché de presse.

Dans le Safe :
- Degagé SACEM
- Degagé CSA dans un pouvoir probablement villageois
- Attaché de presse qui fourni de l'information aux loups.

Le risk/reward me semble juste meilleur si on tente le plan CSA into SACEM.
