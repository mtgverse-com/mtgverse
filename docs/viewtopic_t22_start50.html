Bon du coup la manip qui avait été postée sur MF fonctionne toujours pour les avatars à gauche :

Sur firefox (aucune idée si ça marche sur chrome), il faut télécharger le module complémentaire Stylus.
Une fois installé, vous venez ici, vous cliquez sur l'icone Stylus dans la barre des modules, vous choisissez le domaine "mtgverse.com" (pas besoin de prendre une plus grosse partie de l'URL) et vous ajoutez / enregistrez ce petit morceau de code pour le style à appliquer au forum :

Code : Tout sélectionner

.postprofile{float: left;}
Et ça fait des chocapics.
